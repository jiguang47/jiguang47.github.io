Go by Example 中文版: 迭代器范围遍历

从 Go 1.23 开始，range 可以遍历迭代器函数。标准库的 iter 包定义了迭代器签名；它允许按需产生值，无需先创建完整的切片。

下面实现一个链表迭代器，并展示如何提前停止遍历。

 
package main

import (
    "fmt"
    "iter"
)

type List[T any] struct {
    head, tail *element[T]
}

type element[T any] struct {
    next *element[T]
    val  T
}

func (lst *List[T]) Push(v T) {
    node := &element[T]{val: v}
    if lst.tail == nil {
        lst.head, lst.tail = node, node
        return
    }
    lst.tail.next, lst.tail = node, node
}

func (lst *List[T]) All() iter.Seq[T] {
    return func(yield func(T) bool) {
        for current := lst.head; current != nil; current = current.next {
            if !yield(current.val) {
                return
            }
        }
    }
}

func main() {
    var numbers List[int]
    numbers.Push(10)
    numbers.Push(13)
    numbers.Push(23)

    for number := range numbers.All() {
        fmt.Println(number)
    }

    for number := range numbers.All() {
        if number >= 13 {
            break
        }
        fmt.Println("before break:", number)
    }
}

当 range 遇到 break 时，传给迭代器的 yield 会返回 false，因此迭代器能够及时停止工作。

 
$ go run range-over-iterators.go
10
13
23
before break: 10
