Go by Example 中文版: 随机数

Go 1.22 引入了 math/rand/v2。它提供伪随机数生成器，API 更简洁，也不再需要手动给包级随机源播种。

 
package main

import (
    "fmt"
    "math/rand/v2"
)

func main() {
    fmt.Print(rand.IntN(100), ",")
    fmt.Println(rand.IntN(100))
    fmt.Println(rand.Float64())
    fmt.Println((rand.Float64() * 5) + 5)

    r := rand.New(rand.NewPCG(42, 1024))
    fmt.Println(r.IntN(100), r.IntN(100))
    r2 := rand.New(rand.NewPCG(42, 1024))
    fmt.Println(r2.IntN(100), r2.IntN(100))
}

随机数不适合生成密码、令牌等安全敏感数据。此类场景请使用 crypto/rand。

更多 API 请参阅 math/rand/v2 文档。
