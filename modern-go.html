Go by Example 中文版: 现代 Go 1.22-1.27

本章汇总 Go 1.22 到 Go 1.27 中最适合日常开发和学习的变化。旧代码大多仍能运行；这些特性用于让新代码更简洁、更清晰。

本章的示例要求对应的最低 Go 版本。当前站点按 Go 1.27 编写。

Go 1.22：整数 range。可以直接对非负整数进行 range，省去计数器变量的初始化和比较。

 
for i := range 5 {
    fmt.Println(i)
}
// 0 1 2 3 4

Go 1.22：增强的 HTTP 路由。net/http 的 ServeMux 模式支持方法匹配和路径通配符；路径参数可通过 Request.PathValue 读取。

 
mux := http.NewServeMux()
mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "user: %s\n", r.PathValue("id"))
})

http.ListenAndServe(":8080", mux)

Go 1.23：迭代器。range 可以遍历迭代器函数，标准库还提供了 iter、slices 与 maps 的配套工具。请参阅本站的迭代器范围遍历章节。

 
for value := range sequence {
    fmt.Println(value)
}

Go 1.24：泛型类型别名。现在可以为泛型类型声明别名；这对逐步迁移 API 或给复杂类型起更短的名字很有帮助。

 
type Set[T comparable] = map[T]struct{}

var tags Set[string]
tags = make(Set[string])
tags["go"] = struct{}{}

Go 1.24：模块工具。使用 go get -tool 将开发工具记录在 go.mod 的 tool 指令中，团队成员可通过 go tool 使用同一版本。

 
$ go get -tool golang.org/x/tools/cmd/stringer
$ go tool stringer -type=Status

// go.mod
tool golang.org/x/tools/cmd/stringer

Go 1.24：现代基准测试。新的 b.Loop 比手写 b.N 循环更不容易出错，并能确保昂贵的准备和清理逻辑每次基准运行只执行一次。

 
func BenchmarkIntMin(b *testing.B) {
    for b.Loop() {
        IntMin(1, 2)
    }
}

Go 1.26：new(expr) 与 go fix。new 现在可直接接受表达式作为初始值。go fix 的 modernizer 可将旧写法自动迁移到现代语言和标准库习惯；提交前仍应运行测试并检查 diff。

 
point := new(struct{ X, Y int }{X: 3, Y: 4})
fmt.Println(point.X, point.Y)

$ go fix ./...
$ go test ./...

Go 1.27：泛型方法。非泛型类型的方法现在可以声明自己的类型参数，适合把与某个数据类型紧密相关的泛型操作放到该类型的命名空间中。接口方法不能声明类型参数，泛型方法也不能用于实现接口方法。

 
type Registry struct {
    values map[string]any
}

func (r *Registry) Get[T any](key string) (T, bool) {
    value, ok := r.values[key]
    if !ok {
        var zero T
        return zero, false
    }
    typed, ok := value.(T)
    return typed, ok
}

name, ok := registry.Get[string]("name")
